# ClimaOP

API de clima construida con FastAPI y Postgres/SQLite.

## Descripción

Esta aplicación permite gestionar información meteorológica de diferentes ciudades de manera sencilla. Sus principales funcionalidades son:

- **Gestión de Ciudades:** Registrar, listar, actualizar y eliminar ciudades de la base de datos.
- **Datos Automáticos:** Obtención automática de coordenadas y clima actual al registrar una ciudad.
- **Ranking:** Visualización de ciudades ordenadas por temperatura.
